## Installer l'appli (téléphone ou ordinateur)

**Pas besoin de télécharger de fichiers** : ouvrez le lien ci-dessus, puis :

| Appareil | Comment faire |
|---|---|
| **Android** (Chrome) | Bouton **« Installer l'appli »** en haut de la page, ou menu **⋮** → **Installer l'application** |
| **iPhone / iPad** (Safari) | Bouton **Partager** (carré avec une flèche) → **Sur l'écran d'accueil** → **Ajouter** |
| **PC / Mac** (Edge ou Chrome) | Bouton **« Installer l'appli »** en haut de la page, ou icône d'installation dans la barre d'adresse |

L'icône ABC Tracker apparaît alors sur l'écran d'accueil ou dans le menu Démarrer.
L'appli s'ouvre dans sa propre fenêtre, fonctionne sans connexion et se met à jour toute seule.

## Confidentialité

- Aucune donnée n'est envoyée sur Internet : tout reste **chiffré sur l'appareil**.
- Pour changer d'appareil, utilisez **Exporter / Importer une sauvegarde** dans l'appli.
- Sur iPhone, l'appli installée a sa propre mémoire, séparée de Safari : installez-la avant de commencer vos saisies.
